# Demo-Real-Estate-Scraper
A Python-based Selenium scraper that collects property listings from a real estate website. Saves data in JSON, CSV, and Excel formats. Includes a demo mode with sanitized sample data for safe sharing


This project demonstrates a Selenium-based scraper using Page Object Model, pagination handling, retries, and structured exports.

The repository runs in demo mode by default. Target-specific URLs and real data have been removed.

Users must ensure they have permission to collect data from any site they adapt this for.
